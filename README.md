## 将部署、维护与切换集中到一个入口

海鸥工坊是面向 Codex、Claude Code 与 DeepSeek Harness 的本地管理工作台。通过清晰的版本分区与平台入口，把配置安装、环境诊断、技能接入、REA 集成、备份和卸载恢复组织为可追踪的操作流程。

**本仓库用于产品展示、使用说明和版本发布，不提供完整源码、技能正文或原始资源包。** 本地完整工程独立保留；这里不是可直接构建的软件源码仓库。

## 核心能力

| 能力 | 说明 |
|---|---|
| 三版独立管理 | Codex、Claude、DeepSeek 分开配置，减少版本混用和指令来源冲突 |
| 图形化操作 | Windows 桌面入口，统一安装、校验、备份、维护与启动操作 |
| 分平台启动包 | 按版本提供 Windows、macOS、Linux 启动脚本包；后二者尚未原生实机验收 |
| 轻量配置安装 | 配置与 REA 接入一起处理；大型逆向工具由用户在工具中心独立选择 |
| 阶段进度与日志 | 显示执行阶段、耗时与成功/失败状态，不将等待时间冒充下载百分比 |
| 可恢复卸载 | 已删除文件跳过；受管独立文件先备份，再删除或恢复安装前内容 |
| 共享配置保护 | REA 局部移除保留其他 MCP、模型和账号设置；无法安全判定归属时停止 |
| 界面体验 | 居中窗口、同窗口入场动画、独立公告、主界面动效与 QQ/TG 点击复制 |

## 选择版本，再选择系统

- **Codex 版**：管理 Codex 的本地配置与扩展入口，客户端需另行准备。
- **Claude 版**：管理 Claude 的独立配置与 REA 接入，保留既有用户设置。
- **DeepSeek Harness 版**：管理独立 Harness profile，按需准备客户端并启动本地 Web 工作台。

技能与工具接入是软件能力，**不意味着本仓库附带数百个技能文件**；本仓库不托管这些正文或压缩归档。

## 下载与开始

1. 前往本仓库的 **Releases** 页面。若尚无附件，说明维护者还未发布可下载版本。
2. Windows 桌面用户选择 Windows 完整程序 ZIP，完整解压后运行 `海鸥工坊.exe`。
3. 选择对应版本与本机系统，查看目标目录，再进行配置安装与校验。
4. 根据需要独立安装大型工具；配置校验通过不等于所有外部工具、账号和云模型均已配置。
5. 指令配置变化后新建会话验证效果；安装或卸载配置不会清空历史对话。

现有附件文件名可能保留 `Seagull-` 前缀；展示名称统一为 **Haiou Workshop**。GitHub 自动生成的源码归档只包含本展示仓库文件，不能替代程序安装包。
