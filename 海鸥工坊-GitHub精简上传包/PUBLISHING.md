# 发布此精简仓库

## 当前上传页面

1. 取消当前失败的上传，重新进入 Add file → Upload files。
2. 打开桌面的“海鸥工坊-GitHub精简上传包”。
3. 把本文件夹里面的文件和 docs 文件夹拖入，不要把外层文件夹整体套进去。
4. 等待文件列表完整出现，提交说明填写 `Add Haiou Workshop documentation`，确认提交。
5. 回到仓库首页检查：第一层应直接显示 README.md，截图能显示，没有 resources、skills、源码或压缩包。

本包只有 9 个文件，不需要分批上传。`.gitignore` 是预防误提交的辅助文件，不应依赖它过滤网页拖拽；请只上传本包实际列出的内容。

## 程序附件分开处理

完整 Windows 程序和各系统启动 ZIP 原先放在“海鸥工坊-GitHub发布包/02-Release附件”。不要拖入源码上传页面。完成分发条件核对后，再在 Releases 页面添加所需附件。

当前程序包仍可能嵌入技能和原文资源：本精简包没有这些文件，并不表示旧程序包也已剥离它们。未确认的第三方内容不要公开分发。不要上传本地备份、真实配置、日志、令牌或 API Key。

## 不再需要的构建工作流

此精简包不提供源码，不附带 GitHub Actions 构建工作流。若此前已提交完整源码或含敏感内容的文件，上传这个包不会自动删除旧文件或历史提交，应另外检查仓库状态；本包没有自动修改远程仓库。
