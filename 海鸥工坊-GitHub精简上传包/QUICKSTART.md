# 快速上手

## Windows 桌面版

1. 在 Releases 中选择维护者发布的 Windows 程序包，不选择自动生成的 Source code 归档。
2. 完整解压，不要在压缩包中直接运行。
3. 运行 `海鸥工坊.exe`，依次经过启动动画、公告与主界面。
4. 选择 Codex、Claude 或 DeepSeek，再选择 Windows，确认界面显示的目标目录。
5. 点击安装配置，观察阶段进度与日志；失败时查看具体错误，不把资源正常或进度结束当成安装成功。
6. 点击校验配置，随后启动对应客户端。账号与模型由用户自行配置；需要验证新指令时新建会话。

## macOS / Linux

使用对应版本与操作系统的脚本包，不使用 Windows EXE。完整解压，阅读包内说明后运行对应脚本。两个平台的原生实机验收尚未完成。

## 工具与卸载

- 大型逆向工具从工具中心按需安装，不随配置安装自动下载。
- 卸载配置仅针对该版安装记录中的受管内容；已删除文件跳过。
- 独立受管文件先保存卸载前快照，再移除或恢复安装前文件。
- 共享配置仅移除本工具项目。账号、其他 MCP、历史会话、共享运行时及备份不属于配置卸载删除范围。
- 如出现冲突、权限或占用错误，保留日志并反馈，不手动清空整个用户配置目录。
