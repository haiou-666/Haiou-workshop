# 常见问题

## 为什么看不到源码和几百个技能？

这是精简的展示与发布仓库，不提供完整源码、技能正文、原始压缩归档或构建依赖。README 介绍软件能力，不表示这些内容在仓库中可下载。

## 下载 Source code 能运行软件吗？

不能。本展示仓库的自动源码归档只是这些说明和截图。请使用维护者在 Releases 中实际发布的程序附件。

## 精简仓库会让现有软件少功能吗？

本次只单独整理上传内容，没有修改本地完整工程或现有 EXE。完整发布附件内原有技能等资源也没有因此删除。

## 不上传技能正文，就可以直接发布现有 EXE 吗？

不能仅凭仓库不含正文作出判断。二进制和启动包中仍可能嵌入原始技能、提示词或资料；它们需要单独核对再分发条件。参见 THIRD-PARTY-NOTICES.md。

## 校验通过为什么旧对话还是原来的风格？

文件校验与模型会话效果不是同一件事。旧会话不会因为删除或安装文件自动重置，独立桌面客户端也可能使用不同配置路径。请核对目录、重开客户端或新建会话。

## 卸载是否会清空账号和聊天？

配置卸载不清空历史对话，不删除共享运行时或独立安装的工具。共享配置中的其他项目应保留；受管文件会先备份。遇到无法安全识别的冲突时会停止并显示错误。
